# AI Field Automator

Fill Backdrop fields from other fields, page content, or media. Use it to draft summaries, assign terms, rewrite text, or prepare other field values using rules you set.

## Requirements

Backdrop CMS 1.x, PHP 8.2 or later, and AI, Field UI, and List. Some automator types require additional modules or specific field types.

## Installation

1. Install and enable the module using the official [Backdrop CMS instructions](https://backdropcms.org/user-guide/modules).
2. Open a field’s settings and enable **AI Automator**. Choose the source, prompt, model, and when to run the rule.

See the [module wiki](https://github.com/backdrop-contrib/ai_field_automator/wiki) for setup, use, and troubleshooting.
